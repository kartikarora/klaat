Klaat

Kodelabs As A Thing

Convert Google Docs and Markdown into interactive codelabs. A fast, native command-line tool built with Kotlin and GraalVM for creating beautiful, step-by-step tutorials.

Quick Start

1

Export from Markdown

Create a codelab from a Markdown file:

klaat-snapshot export my-tutorial.md -o output -f html
2

Export from Google Docs

Convert a Google Doc to a codelab (requires one-time authentication):

klaat-snapshot export https://docs.google.com/document/d/YOUR_DOC_ID -o output -f html
3

Preview Locally

Start a local server to preview your codelabs:

klaat-snapshot serve -dir output -addr localhost:9090

Open http://localhost:9090 in your browser

Documentation

Commands

klaat-snapshot export

Convert a source document to codelab format

klaat-snapshot export [SOURCE] [OPTIONS]

Options:

  • -o, --output DIR - Output directory
  • -f, --format FORMAT - Output format: html, md, offline
  • -ga ID - Google Analytics ID
  • -prefix URL - Asset URL prefix
  • -e, --environment ENV - Environment: web, kiosk

klaat-snapshot serve

Start a local preview server

klaat-snapshot serve [OPTIONS]

Options:

  • -dir PATH - Directory to serve
  • -addr HOST:PORT - Server address (default: localhost:9090)

klaat-snapshot version

Display version information

klaat-snapshot version

Markdown Format

Klaat uses Markdown with YAML frontmatter:

---
id: my-codelab
summary: Brief description
categories: Android, Kotlin
status: Published
authors: Your Name
tags: tutorial, beginner
---

# Codelab Title

## Step 1: Introduction
Duration: 5

Content for step 1...

## Step 2: Next Step
Duration: 10

Content for step 2...

Google Docs Format

Structure your Google Doc with:

  • Metadata Table - Optional two-column table at the start
  • Heading 1 - Each represents a step
  • Content - Paragraphs, lists, code blocks, images

About

Klaat is a Kotlin reimagining of Google's claat tool. It provides the same functionality with improved performance through GraalVM native compilation, making it faster to start and more memory-efficient.

Why Klaat?

  • Fast - Native binary with instant startup
  • Lightweight - No JVM required, minimal dependencies
  • Modern - Built with Kotlin, leveraging modern JVM features
  • Compatible - Works with existing claat content and formats

Built With

  • Kotlin - Modern JVM language
  • GraalVM Native Image - Ahead-of-time compilation to native code
  • Google Docs API - For importing from Google Docs
  • Flexmark - Markdown parsing and rendering
