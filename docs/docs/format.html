Format Overview

Welcome to the Klaat Format Guide. Klaat processes structured document sources (Markdown and Google Docs) into interactive step-by-step tutorials.

Codelabs are structured around Steps. Each step corresponds to a slide in the interactive tutorial. Underneath, content maps to code blocks, text formatting, semantic infoboxes, call-to-action buttons, surveys, tables, and media embeds.

Tip: This format guide is rendered using the actual <klaat-kodelab> and <klaat-kodelab-step> web components! You can use the left drawer and arrow keys to navigate.

Metadata Configuration Reference

Every codelab begins with a metadata block that defines configuration options like URL, authors, tracking ID, category, and target environments:

Field Required Type Description
id Optional String Unique URL-safe directory identifier. Defaults to sluggified summary.
summary Required String Short summary used in cards and catalog listings.
categories Optional List/CSV Topic categories for indexing and filtering.
environments Optional List/CSV Target environments (default: Web).
status Optional List/CSV Publication status (Published, Draft, Deprecated).
authors Optional List/CSV Author name(s) responsible for the content.
feedback_link Optional String URL or mailto link for feedback (displayed in drawer footer).
duration Optional Integer Total tutorial duration in minutes (overrides sum of step durations).

Markdown Document Format

Markdown files are parsed with Flexmark and must conform to the following hierarchy:

  • YAML Frontmatter: Top of the file enclosed in triple dashes ---.
  • Heading 1 (# Title): The overall title of the codelab.
  • Heading 2 (## Step Title): Denotes each new step/slide.
  • Duration Specification: Directly below each Heading 2, specify Duration: MM (minutes), Duration: HH:MM:SS / MM:SS (e.g. Duration: 0:01:30), or Duration: 0:00:00 (ignore) to exclude the step from total countdown time.

Markdown Template Example

---
id: intro-to-kotlin
summary: Learn modern Kotlin programming
authors: Kartik Arora
categories: kotlin, tutorial
status: published
feedback_link: mailto:dev@kartikarora.me
---

# Introduction to Kotlin

## Setup Environment
Duration: 0:02:00

Install Kotlin and configure your IDE...

## Write First Program
Duration: 0:05:00

```kotlin
fun main() = println("Hello, Klaat!")
```

Google Docs Document Format

Google Documents use visual styles mapped to codelab structures:

  • Metadata Block: Two-column table at top with keys on the left and values on the right.
  • Title Style: Document title.
  • Heading 1: Step boundaries.
  • Duration Text: Plain text Duration: 5 under Heading 1.

Text & Typography

Klaat supports standard rich typography formatting:

  • Bold: **bold text** → bold text
  • Italics: *italic text* → italic text
  • Inline Code: `var count = 0` → var count = 0
  • Links: [Title](https://example.com) → Title
  • Pull Quotes: Markdown blockquotes without tag attributes render as high-impact pull quotes:

fun calculateRemainingTime(steps: List<Step>): Duration {
    return steps.filter { !it.excludeDuration }
        .map { it.duration }
        .reduce(Duration::plus)

Semantic Infoboxes (Alert Callouts)

Infoboxes are styled callouts created using Markdown blockquotes with an attached type tag attribute:

Special (Info / Tip) — {.special}

Information: Special callouts highlight helpful tips, recommendations, or non-critical background context.

Positive (Success) — {.positive}

Success: Positive callouts celebrate milestones, successful test runs, or completed steps.

Warning (Caution) — {.warning}

Caution: Warning callouts alert readers to potential stumbling blocks, deprecations, or prerequisite checks.

Critical (Error / Security) — {.critical}

Critical: Critical callouts warn against severe errors, data loss risks, or security vulnerabilities.

Source Markdown

> **Tip**: Helpful recommendations or details. {.special}
> **Success**: Milestones and achievements. {.positive}
> **Warning**: Important prerequisites and cautions. {.warning}
> **Critical**: Do not commit private credentials! {.critical}

Action Buttons & Custom Icons

A Markdown link becomes an interactive pill button only when appended with a button tag attribute. Standalone links without button tags remain standard inline links.

Primary Solid Button with Custom Icon

Use {.buttonPrimary} (or shorthand {.button}) and optional icon=<name>:

menu_bookRead Documentation

Secondary Outlined Button with Custom Icon

Use {.buttonSecondary} and optional icon=<name>:

mailSend Feedback

Automatic Download Icon Detection

Links containing "download" in their text or targeting archive files (.zip, .tar.gz) automatically show the download icon:

downloadDownload Sample Asset

Kodelab Web Components (<kodelab-*>)

Klaat HTML output is powered by lightweight Web Components with zero external JS frameworks. Both <klaat-kodelab*> and <kodelab-*> tags are supported:

Component Tag Key Attributes Functionality
<klaat-kodelab>
<kodelab-codelab>		 id, title, environment, feedback-link Container component. Handles drawer navigation, timer countdown, progress bars, keyboard shortcuts, and URL routing.
<klaat-kodelab-step>
<kodelab-step>		 label, duration, exclude-duration Encapsulates an individual slide/step with duration tracking.
<klaat-kodelab-survey>
<kodelab-survey>		 survey-id Interactive questionnaire with radio selection and localStorage state.
<klaat-kodelab-analytics>
<kodelab-analytics>		 gaid Google Analytics integration tracking step transitions.

Include the CDN assets in any HTML page to use the web components anywhere:

  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Interactive Tutorial</title>

  <!-- CDN CSS -->
  <link rel="stylesheet" href="https://distribute.kartikarora.me/css/kartikarora.1.7.0.css">
  <link rel="stylesheet" href="https://distribute.kartikarora.me/css/klaat-elements.css">
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" rel="stylesheet">
</head>
<body>

  <klaat-kodelab id="my-codelab" title="Interactive Tutorial" feedback-link="mailto:dev@kartikarora.me">
    <klaat-kodelab-step label="Step 1: Introduction" duration="2">
      <h2>Welcome!</h2>
      <p>This is step one.</p>
      <aside class="positive"><p><strong>Tip:</strong> Use arrow keys to navigate!</p></aside>
    </klaat-kodelab-step>
  </klaat-kodelab>

  <!-- CDN JS -->
  <script src="https://distribute.kartikarora.me/js/kartikarora.1.7.0.js"></script>
  <script src="https://distribute.kartikarora.me/js/klaat-elements.js"></script>

</html>
