AI Agent Skills Benchmark

Klaat bundles official AI formatting skills (such as klaat-markdown-author, klaat-cli, and klaat-gdocs-author) that install into 55+ coding agent environments via klaat install-skills. To ensure these guidelines genuinely improve agent output and prevent hallucination, we evaluate them against both live LLM agents and deterministic compiler validation.

Evaluation Methodology

Our eval suite uses a two-stage approach combining autonomous agent simulation and compiler-backed deterministic validation:

psychology 1. Autonomous Invocation Test

We do not hardcode SKILL.md into the prompt. Instead, we present the agent with a catalog of skill descriptions and a read_skill tool. We check whether the model independently chooses to invoke read_skill("klaat-markdown-author") when handed a codelab prompt, and whether it correctly leaves the tool untouched for general markdown requests.

fact_check 2. Deterministic Compiler Verification

Rather than relying only on subjective LLM judges, we feed the agent's raw output directly into Klaat's official MarkdownParser. A test only passes if the output extracts valid YAML metadata (id, summary, categories), valid per-step durations (Duration: > 0), and produces compilable HTML with zero parser errors.

Run this eval locally: 
./gradlew evalSkills -PupdateDocs=true
