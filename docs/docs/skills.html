Evaluation Methodology

Our eval suite combines autonomous agent tool-calling simulation (gemini-4-hydrogen, thinkingLevel: "low") with deterministic skill-specific graders and an LLM-as-a-Judge rubric (gemini-4-neon, thinkingLevel: "low"):

psychology 1. Autonomous Invocation Test

We never pre-inject SKILL.md into the prompt. Instead, the agent only sees the skill catalog descriptions and a read_skill tool, verifying both sensitivity (calling the right skill) and specificity (leaving the tool untouched on distractor prompts).

fact_check 2. Deterministic Graders

klaat-markdown-author outputs are compiled with Klaat's official MarkdownParser; klaat-cli outputs are checked for valid flags and zero hallucinated options; klaat-gdocs-author outputs are checked for metadata tables, headings, and Duration: syntax.

gavel 3. LLM-as-a-Judge Rubric

gemini-4-neon (thinkingLevel: "low") scores both Baseline and Agent outputs on a 1–5 structured JSON rubric (adherenceScore, clarityScore, score, passed, and reasoning) alongside deterministic checks.

EVALUATION SPECIFICATION & AUDIT TRAIL
Dataset Composition 16 prompts across easy, medium, and hard tiers: 6 klaat-markdown-author, 3 klaat-cli, 3 klaat-gdocs-author, and 4 non-codelab distractors (CONTRIBUTING.md, blog post, deployment runbook, README.md).
A/B Protocol Every prompt runs twice under identical conditions: Baseline (standard assistant prompt, no skills, no tools) vs. With Klaat Skill (catalog descriptions + read_skill tool).
Default Models Agent: gemini-4-hydrogen (thinkingLevel: "low") • Judge: gemini-4-neon (thinkingLevel: "low").
Deterministic Checks Markdown: MarkdownParser compilation + metadata/duration/callout AST checks. CLI: valid subcommands/flags and zero hallucinated flags (--watch, --port, --output-dir, --theme). Google Docs: metadata table, Heading 1/2 hierarchy, and Duration: syntax.
