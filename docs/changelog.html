Stable Version 2.0.1

2026-09-14

Maintenance release modernizing brand integration, upgrading dependencies, and preventing quote regression in code comments.

  • feat Upgrade to @kartikarora/brand 1.8.0 design system across all web components and documentation.
  • fix Prevent quote and contraction parser regressions inside source code comments.
  • chore Bump Gradle dependencies and library versions to latest stable.

Stable Version 2.0.0

2026-08-19

Major release introducing native Klaat Web Components (<klaat-codelab>, <klaat-step>), interactive action buttons, and duration modernization.

  • feat Native Klaat web components (<klaat-codelab>, <klaat-step>, action buttons) with CDN delivery.
  • feat Action Buttons syntax (.buttonPrimary, .buttonSecondary, .button) with custom icon support.
  • feat Interactive codelab showcase and format guide preview directly inside browser.
  • refactor Modernize duration parsing with kotlin.time.Duration API and dynamic remaining time calculation.
  • fix Fix survey inline code formatting and button step fence rendering.

Stable Version 1.0.0

2026-07-21

Initial general availability release of Klaat — a modern Kotlin-based spiritual successor to Google's claat tool.

  • feat Complete Google Docs and Markdown tutorial parsing pipeline.
  • feat Export to HTML, Markdown, and self-contained Offline bundles.
  • feat Embedded local Ktor preview server with live reloading and auto-launching browser.
  • feat GraalVM native image binaries for macOS (Apple Silicon) and Linux (x64, ARM64).
  • feat AI agent skill suite (klaat-cli, klaat-markdown-author, klaat-gdocs-author, klaat-native-manager).
